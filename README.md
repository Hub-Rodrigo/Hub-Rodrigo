## 🚀 Projetos em Desenvolvimento

Projetos desenvolvidos para aplicar conhecimentos de programação, análise de dados, integração de sistemas e Business Intelligence em situações práticas.

### 📊 DataVision BI

Plataforma de Business Intelligence para conexão, consulta e visualização de dados provenientes de diferentes fontes.

**Tecnologias:** Python, FastAPI, React, PostgreSQL e Docker.

**Objetivo:** facilitar o acesso aos dados e transformar informações empresariais em visualizações e indicadores.

### 🧾 Conversor de Extratos PDF para Excel

Aplicação desktop para extração, tratamento e organização de informações financeiras provenientes de arquivos PDF.

**Tecnologias:** Python, Pandas, pdfplumber, Tkinter e OpenPyXL.

**Objetivo:** automatizar a conversão de extratos bancários em planilhas estruturadas, facilitando análises e conciliações.

### 🗄️ SQL Analyst Lab

Ambiente interativo para praticar SQL, consultas e análise de dados utilizando uma base de dados relacional.

**Tecnologias:** Python, Streamlit e SQLite.

**Objetivo:** desenvolver conhecimentos em consultas SQL, relacionamentos e exploração de dados.

### 🔎 Web Data Extractor

Projeto de aplicação para extração e tratamento de informações de diferentes fontes de dados.

**Objetivo:** desenvolver uma solução para coleta, transformação e exportação de dados em formatos estruturados, facilitando sua utilização em ferramentas de análise.
